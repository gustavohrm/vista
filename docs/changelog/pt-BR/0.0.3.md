# 0.0.3

## Added

- Escolha um tema nas Configurações, entre Luz do dia, Neutro e Oceano, e ajuste o contraste e o movimento, ou deixe cada um seguir o sistema.
- Gerencie todos os espaços de trabalho nas Configurações: crie, edite e exclua, e pesquise pelo nome, ignorando acentos e com os resultados mais próximos primeiro.
- Remova um espaço de trabalho dos recentes no seletor; ele volta quando você o abre de novo.
- A tela inicial lista seus cinco espaços de trabalho mais recentes, e a barra de título fica no topo mesmo sem espaço de trabalho aberto.

## Changed

- O app para desktop desenha a própria barra de título, com Minimizar, Maximizar e Fechar. No Windows, deixar o ponteiro sobre Maximizar mostra os Layouts de Ajuste.
- A pesquisa do seletor de espaços de trabalho mostra os melhores resultados primeiro, e uma lista longa de espaços de trabalho nas Configurações termina em Ver todos.
- No navegador, recarregar a página mantém as Configurações abertas na página em que você estava.
- O download do app para desktop no app web mostra a versão que baixa, como `v0.0.3`.

## Fixed

- No desktop, abrir uma pasta não falha mais com "Failed to open the selected folder." Uma pasta que o Vista 0.0.2 lembrava pode pedir para ser escolhida de novo uma vez.
- Uma ação de espaço de trabalho não termina mais depois de uma mais nova e a desfaz, como uma pasta lenta para abrir substituindo o espaço de trabalho para o qual você trocou nesse meio-tempo. ([#53](https://github.com/gustavohrm/vista/issues/53))
- No navegador, um espaço de trabalho de uma pasta escolhida sem acesso aos arquivos mantém suas abas quando você o reabre na mesma sessão.
- Enquanto o navegador bloqueia o armazenamento, o esquema Claro ou Escuro que você escolhe continua escolhido.
- Campos de texto e chaves usam a cor de contorno do tema, então ficam mais fáceis de ver.
- As dicas abrem do lado em que cabem e ficam ao lado do botão quando o layout muda.
- O seletor de espaços de trabalho fica dentro da janela quando ela estreita, e `Tab` move o foco para fora dele.
