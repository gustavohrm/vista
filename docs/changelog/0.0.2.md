# 0.0.2

## Added

- Group folders into workspaces: give each a name, icon, and colour, switch between recent ones, and reopen each with its tabs and expanded folders. A folder's `.vista/workspace.json` file keeps its workspace's details.
- Open CSV files as a table with a header row, and move rows by dragging. A file over 10,000 cells opens as raw text.
- Reorder tabs by dragging, with `Shift+Arrow` keys, or from the command palette, and tell apart tabs whose files share a name.
- Copy a file's path, or reveal it in the file manager on desktop, from its tab, the explorer, or the command palette.
- See the open file's path in the path bar, and find commands by category in the command palette.
- Settings is now a page, with the theme, About, and What's New, which shows what each version changed.
- Download the desktop app from the web app, for Windows or for Linux on x86_64.

## Changed

- The window is redesigned around one framed document, with an activity rail, the document's actions in the tabs row, and no menu bar.
- Vista has a new logo and app icon.
- The desktop app checks for updates only when you choose Check for Updates in Settings, or turn on Check at startup. A version found at startup shows as a small notice instead of interrupting. ([#34](https://github.com/gustavohrm/vista/issues/34))
- The folder Vista 0.0.1 remembered opens as your first workspace.

## Fixed

- On Linux, the desktop app can read `.vista`, `.github`, and other entries whose names start with a dot inside an opened folder.
- On Linux, a folder whose name ends in a backslash keeps its contents.
- A Markdown image that can't be shown shows its placeholder icon again.

## Security

- The web app sends a content security policy and security headers, and builds its download links from its configured address rather than the request's.
